# GitHub #40：后接入设备覆盖远端 manifest 身份

https://github.com/dolag233/Serpent/issues/40

设计：`docs/internal/implementation/2026-09-11-webdav-sync-followups.md` §5.3

## 现象

第二台电脑「打开同步资源库」并同步后，远端 `manifest.json` 的 `libraryId`/`displayName` 变成该机的值。第一台再同步不保证改回去。资产条目匹配靠 `syncId`，身份字段会在设备间跳变。

## 根因

`syncOnce` 无条件 PUT 以本机 `localManifest` 为起点的 JSON。缓存为空时 `createEmptyManifest` 使用本机 `libraryId`/`displayName`。打开同步库若未把远端 ID 钉进 `library` 表，或 `createLibrary` 用目录 basename 覆盖显示名，就会写出另一套身份。

## 应对

远端已有合法 `libraryId` 则写回必须保留。打开同步库时本地 `library_id` = 远端 ID。本机 ID 与远端不同则拒绝覆盖，提示绑定错误。禁止空 `entries` 覆盖非空远端 manifest。

## 验证

engine 单测：B 空缓存同步后远端仍是 A 的 ID。验收 ID：`SYNC-ID-001`。
