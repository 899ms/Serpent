# GitHub #39：标签/描述不参与 WebDAV 同步

https://github.com/dolag233/Serpent/issues/39

设计：`docs/internal/implementation/2026-09-11-webdav-sync-followups.md` §5.4

## 现象

手册写首次同步上传资产、元数据与清单。实际远端没有 `metadata/`，`metadataVersion` 停在 1。后接入设备看不到标签和描述。文件夹为 0 行时先核对自动同步是否把路径传上去（另一张 P0），本单管元数据通道。

## 根因

`SYNC_METADATA_DIR` 只在 `src/shared/sync-paths.ts` 定义。`SyncLibraryPort` 无元数据读写。上传分支写死 `metadataVersion: 1`。

## 应对

首期：人标签、描述、评分、收藏，每资产 sidecar `metadata/entries/<syncId>.json`，与 manifest `metadataVersion` 同号递增。改这些字段必须能触发自动同步。打开同步库下载文件后应用 sidecar。合集成员、AI 标签、插件目录不做。默认实现通道，不默认只改手册。

## 验证

极小文件 + 标签字符串；A 同步后 NAS 有 sidecar；B 打开后 tags/description 非空。验收 ID：`SYNC-META-001`。
